MyVideo Prototype - Static Deployment Package

Files:
- index.html : deployable single-page prototype

Recommended hosting:
1. Netlify Drop
   - Go to https://app.netlify.com/drop
   - Drag this folder or ZIP onto the page
   - Netlify will create a public HTTPS URL immediately
   - You can rename/customize the site URL in Site settings

2. GitHub Pages
   - Create a GitHub repository
   - Upload index.html to the repository root
   - Settings > Pages > Deploy from branch > main / root
   - GitHub will provide a permanent public URL

3. Vercel
   - Create a project and import the folder/repository
   - No framework is needed; index.html can be served as a static site

Notion:
- Paste the public URL into Notion and choose "Create embed"
- Or type /embed and paste the public URL

Important:
- Do NOT upload only the local .html file into Notion if you want an always-accessible interactive demo URL.
- The prototype must be hosted on a public HTTPS URL first.
